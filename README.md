# QuickPath Opener - 路径快开助手

一款轻量但强大的 AutoHotkey 脚本，它能极大地增强你的 `Win + E` 快捷键。只需复制路径，一键即可在资源管理器中打开，告别繁琐的“打开资源管理器 -> 粘贴路径 -> 回车”的传统流程。

## ✨ 功能亮点

- **剪贴板驱动**: 复制路径，按下 `Win + E`，文件夹立即呈现在眼前！
- **智能路径修正**: 自动为你处理各种“不规范”的路径格式：
  - 清理路径前后的多余空格。
  - 剥离路径两端的英文双引号 (`"`)。
  - 自动将 `/` 转换为 Windows 标准的 `\`。
  - 识别并清理 `file:///` 格式的路径。
  - 兼容以 `\` 结尾或不以 `\` 结尾的各种情况。
- **文件路径智能转换**: 如果你复制的是一个文件的路径，它会自动打开该文件所在的 **父文件夹**。
- **无缝回退**: 如果你的剪贴板中没有合法的路径，`Win + E` 会恢复其原始功能，正常打开“此电脑”或“快速访问”。
- **极致轻量**: 脚本在后台运行时，CPU 占用几乎为零，内存占用仅 2-3MB，对系统性能无任何影响。

## 🚀 安装与使用

本脚本依赖 **AutoHotkey** 运行。如果您从未安装过它，请先根据以下步骤进行设置。整个过程不超过5分钟。

### 第一步：安装 AutoHotkey

1.  访问 AutoHotkey 官方网站：[https://www.autohotkey.com/](https://www.autohotkey.com/)
2.  下载 **v1.1** 版本（请注意，此脚本是为 v1.1 版本编写的）。
3.  运行安装程序，根据屏幕提示完成安装（选择“快速安装”即可）。

### 第二步：获取并放置脚本

1.  下载本仓库中的核心脚本文件：`QuickPathOpener.ahk`。
2.  将这个文件放置在您希望的任意位置，例如桌面或者一个专门的工具文件夹中。

### 第三步：运行脚本

**双击** `QuickPathOpener.ahk` 文件即可。

运行后，你会在任务栏右下角的托盘区域看到一个绿色的 "H" 图标，这代表脚本已成功在后台运行。

至此，所有功能已全部激活！

## 💡 如何使用

1.  在任意地方复制一个文件夹或文件的路径到剪贴板。
    - 例如：`D:\我的项目\某个应用`
    - 或：`"C:\Users\你的用户名\Desktop\年度报告.docx"`
    - 或：`file:///D:/下载/图片.jpg`
2.  按下键盘上的 `Win + E` 快捷键。
3.  Windows 资源管理器将立即打开到目标文件夹！

## ⚙️ 设置开机自启（永久生效）

为了避免每次开机都手动运行脚本，你可以简单地将其设置为随 Windows 启动。

1.  首先，右键点击你的 `QuickPathOpener.ahk` 文件，选择 **创建快捷方式**。
2.  按下 `Win + R` 键，打开“运行”对话框。
3.  在对话框中输入 `shell:startup` 然后按回车，系统会自动打开“启动”文件夹。
4.  将第一步创建的 **快捷方式文件** 拖动或剪切到这个“启动”文件夹中。

完成！现在，这个便捷的功能将在你每次登录 Windows 时自动准备就绪。
